Bot & Proxy Filtering Engine Settings

Block Datacenter & Cloud Hosting IPs

Blocks traffic originating from AWS, DigitalOcean, Hetzner, OVH, Linode, Google Cloud, Azure, and other VPS servers.

Block VPNs & Commercial Proxies

Blocks NordVPN, ExpressVPN, Surfshark, Proton, Tor exit nodes, and known proxy networks.

Block Timezone Geolocation Mismatch (IP Fighter style)

Compares browser's local timezone with IP geolocation. Blocks users whose location does not match their browser time.

Block Virtual Machine & Software GPU Renderers

Detects SwiftShader, llvmpipe, Mesa, VMware, and VirtualBox display drivers used in headless server bots.
